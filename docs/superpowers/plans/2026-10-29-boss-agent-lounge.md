# Boss Agent Lounge Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the six canonical robots sharing a lounge, animate only proven current work, and display authoritative verified progress in readable charts.

**Architecture:** A pure selector joins current tasks/runs to explicit ActivityProof records; idle mascots remain distinct from actual workers. SVG/CSS components consume that derived view without dispatching work. After real core providers exist, trusted activity writers add a backward-readable optional ProgressV1 field and the dashboard integrates the scene, chart and existing details.

**Tech Stack:** Existing React/Next.js/TypeScript, canonical SVG Avatar, CSS transform/opacity, tsx tests and Playwright; Node >=22.13; no Highcharts/canvas/new dependency required.

**Spec:** `docs/superpowers/specs/2026-10-29-boss-agent-lounge-design.md`, plus approved core and web-command specs in the same directory.
